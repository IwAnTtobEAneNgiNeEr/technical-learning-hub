# Technical Learning Hub

A Vietnamese-first, project-driven route through systems, automation, Java architecture, web, AI, security, and embedded development. Learn one mechanism at a time, then apply it in a small build.

## Start

Clone or download this repository and open `index.html` in a browser. The Hub is static HTML, CSS, and JavaScript; it needs no build step, server, package install, or account. Keep the `assets/` folder beside the HTML pages.

- **Foundations** — 14 entry paths with short diagnostics, ordered concepts, lecture sections, exercises, and related projects.
- **Knowledge** — 113 learning stations with a mechanism flow, key ideas, focused reading/video links, a step-by-step exercise, and a check for understanding.
- **Tracks and projects** — 62 projects with 383 short sessions, evidence prompts, and links back to the relevant concept.
- **AI study prompts** — each foundation module, knowledge station, and project session begins with a context-filled coach prompt. Copy it into your AI agent. It asks the agent to guide one step at a time, wait for your attempt, offer hints before solutions, and finish by checking your evidence.

## Progress and privacy

Notes, session proof, and assessments are saved in the current browser. Use **Progress** to export or import a JSON backup. The Hub does not send progress to a server. Study prompts are displayed locally; they are shared with an AI provider only when you paste them there. Course links and external exercises need an internet connection.

## Layout

Each page is a separate HTML file. `assets/data.js` contains the curriculum; `app.js`, `stations.js`, and `core.js` render pages and manage browser-local progress. This public build removes workstation checkout paths and uses public learning references in place of private project sources.
